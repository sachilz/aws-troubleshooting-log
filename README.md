# AWS Issues and Solutions Tracker

Welcome to the AWS Issues and Solutions repository! This repository serves as a centralized knowledge base for documenting AWS-related issues I encounter, along with step-by-step solutions and resources used to fix them.

## 📂 Repository Structure

- `issues/`: Contains individual folders for each issue documented. Each folder includes a detailed `README.md` and any related attachments (e.g., PDFs, screenshots).
- `templates/`: Contains markdown templates to make it easy to document new issues consistently.

## 📝 How to Add a New Issue

1. Create a new folder inside `issues/` following the naming convention: `XXX-short-issue-description` (e.g., `002-s3-bucket-policy-error`).
2. Copy the file `templates/issue-template.md` into your new folder and rename it to `README.md`.
3. Fill out the details about the issue and the solution in the new `README.md`.
4. Add any relevant files (PDFs, screenshots, logs) to the folder.
5. Update the **Index of Issues** table in this main `README.md` with the new entry.
